### Top Project

#### 🏴 [Spark Expo CTF — Boot2Root VM Hardening & Event Infrastructure](https://github.com/Kashif-Mashi/spark-expo-ctf-hardening)

Organized and hardened a Boot2Root VM (VulnHub's JIS-CTF: VulnUpload) into a
live, competitive Red Team selection challenge for University of Sargodha's
Spark Expo, run for ~10 participants.

- Patched 3 unintended local-root CVEs in the base OS without breaking the intended challenge path
- Designed a new privilege-escalation challenge from scratch, based on GTFOBins
- Obfuscated web paths and flag structure to prevent public walkthroughs from working
- Deployed live via CTFd: 5 chained flags, 750 points, central scoreboard

`VirtualBox` `Ubuntu` `Apache` `PHP` `Kali Linux` `CTFd`
